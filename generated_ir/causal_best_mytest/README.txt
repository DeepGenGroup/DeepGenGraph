Causal attention, generated by MyTest

Test artifacts: group4.ll and group8.ll.
Both use forward bx (workgroup-reverse=0), with group sizes 4 and 8.
Shape BHSD=(1,32,4096,128), BM=BN=128, BK=32, wave64, 256 threads.
Launch: grid=(32,32,1), block=(256,1,1), kernel=Attn_p2, K layout=BHSD.
Use the matching *.launch.json and --causal in launchKernel.py.

The complete MLIR -> MyTest -> LLVM path generates these files. There is no
post-export textual conversion from noncausal LLVM to causal LLVM.
causal.input.mlir includes the causal mask and the query-dependent key bound.
The QK reduction loop carries the same frisk.simplify_loop marker as the best
noncausal input, to expose its four D slices before buffer scheduling.
uniform-masks=0 retains per-element selects; the optional uniform-mask fast
path creates extra compute blocks incompatible with these scheduling passes.

Current best scheduling options:
  retain-fragment-words=32, pv-interleave=4, v-double-buffer=1
  k-dma=64-swizzle, swizzle-k=8:6, k-lds-prefetch=8
  softmax-fragments=pv, k-tail-prefetch=4, cross-bn-k0=1
  defer-lane-sum=approx, local-reduce=approx, chains=4
All options and positional arguments are saved in commands.json.

PrefetchNextKPass now supports a proven nonempty invariant unsigned loop bound
with < or <=, including reversed exit predicates. For this causal export,
the next K0 DMA is issued only when next_tile <= query_tile. Four DMA packets
cover 8192 bytes and overlap the final 32 PV MMACs. The 64 original scalar FP32
sum additions retain the tied-register anchors used by the measured spill fix.
The last causal tile issues no future K0 DMA. Wait/barrier counts and LDS size
are unchanged. Generic regression tests cover inclusive zero, dynamic bounds,
inverted/swapped comparisons, unsafe bounds and tagged register identities.

Reproduce:
  python3 generated_ir/causal_best_mytest/generate.py
  python3 generated_ir/causal_best_mytest/verify.py

GPU test (from repository root):
  bash generated_ir/causal_best_mytest/run_gpu.sh
Or select one variant:
  bash generated_ir/causal_best_mytest/run_gpu.sh group4
  bash generated_ir/causal_best_mytest/run_gpu.sh group8
ATTN_WARMUP and ATTN_REPEAT default to 20 and 100. Each run writes its HSACO,
assembly, compiler log and timing results to a separate runs/ directory.

Validation is recorded in validation.json and validation.log. It executes
actual LLVM with delayed DMA completion and LDS byte-ownership auditing,
checks causal tile bounds and the exact K0 issue sequence, and compares with
an FP64 causal reference (atol=rtol=.01). Cases include first/middle/last query
tiles, changing maxima, dominant future positions inside a diagonal tile,
and large positive/negative scores. Selected cases also check O3 output and
bitwise/trace equality against before_cross_bn/group4.ll.
The complete noncausal instruction graph still matches the measured spill-fix
artifact; see noncausal-regression.log.

GPU timing and target register allocation are not measured locally. The CPU
model does not simulate independent wave timing. Inspect the generated target
assembly for VGPR/scratch/spill when testing on the device.
