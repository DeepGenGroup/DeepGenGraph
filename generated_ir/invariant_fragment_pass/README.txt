Generic loop-invariant operand fragment retention: compiler-generated A/B

Files to test:
  baseline.ll                 --retain-fragment-words=0
  retained_8words.ll           --retain-fragment-words=8
  Corresponding *.launch.json files contain the same launch configuration.

Both files are generated by MyTest from the same input and compiler settings;
no LLVM text patching is performed. The configuration follows the measured
group8 reverse / K128 swizzle winner: BM=BN=128, BK=32, layout=3.3, 256 threads,
4x1 waves, BHSD=(1,32,4096,128), FP16 causal attention. Grid=(32,32,1).
Static LDS is 16384 bytes in both; dynamic shared is 0.

IMPORTANT: baseline.ll is a fresh compiler export, not a byte-identical copy of
the historical best group8_reverse_k128_gep.ll. Both current exports include
the current compiler's LDS-address canonicalization. Measure these two files
together to isolate retention. The historical winner is also included in the
CPU numerical comparison; its existing file is not modified.

Implementation:
  3rd/deepgengraph/lib/Conversion/FriskToBase/RetainInvariantFragments.cpp
  Pass: frisk-retain-invariant-fragments, option max-words=8
  MyTest / RunFriskSHell.sh: --retain-fragment-words=8 (default 0 disables)

The pass runs after thread layout and loop specialization, before LDS packing,
copy scheduling and shared-storage reuse. It uses dependencies/effects, not
Q/K/V names or fixed SSA IDs. In this attention instance it automatically
selects Q[:,0:32], moves its DMA, readiness wait, LDS reads and FP16 scaling
before BN, and retains four <4 x half> values (32 bytes / 8 words per thread).
Register allocation and VGPR/scratch counts require target compilation.

For N=query_tile+1, dynamic IR operation counts:
                              baseline        retained
  Q DMA calls/block           8*N             2+6*N
  K/V DMA calls/block          16*N            16*N
  ordinary b64 LDS reads       144*N           4+140*N
  FP16 Q vector scales         16*N            4+12*N
  vmcnt(0) waits               12*N            1+11*N
  workgroup barriers           16*N            2+16*N
  MMAC calls                   256*N           256*N

Synchronization is regenerated by the compiler. Unlike the earlier LLVM
experiment, readiness moves out of the loop, removing one wait per iteration.
The prologue has a publication barrier before reading Q and a storage-handoff
barrier after those reads, before the loop can reuse that LDS space. This is
not byte-identical to the earlier experimental retained IR.

Reproduce from repository root:
  cmake --build 3rd/deepgengraph/build --target MyTest ThreadTilingTest -j 2
  python3 3rd/deepgengraph/test/check_invariant_fragment_retention.py
  python3 generated_ir/invariant_fragment_pass/generate.py
  OPENBLAS_NUM_THREADS=1 python3 generated_ir/invariant_fragment_pass/verify.py

Target benchmark, from this directory (use separate build directories):
  mkdir -p build-baseline build-retained
  cd build-baseline
  bash ../../../GenHsaco.sh ../baseline.ll 3 kernel.hsaco
  python3 ../../../launchKernel.py --hsaco kernel.hsaco \
      --config ../baseline.launch.json --warmup 50 --repeat 200 --json-output result.json
  cd ../build-retained
  bash ../../../GenHsaco.sh ../retained_8words.ll 3 kernel.hsaco
  python3 ../../../launchKernel.py --hsaco kernel.hsaco \
      --config ../retained_8words.launch.json --warmup 50 --repeat 200 --json-output result.json

Validation:
  LLVM assembler and default<O3>,verify for both files.
  CPU execution of actual LLVM with DMA completion delayed until waits:
  query tiles 0/1/7/8/31, two heads and two random seeds; bitwise equality of
  pass OFF, pass ON and historical best; reference tolerances checked.
  All 4096 retained Q elements are loaded exactly once; K/V and other Q ordered
  global-read traces are unchanged; no unfinished DMA or out-of-tile outputs.
  See validation.json, validation.log, regression.log and manifest.json.

No GPU correctness/performance measurement or gfx936 register-allocation result
is claimed here. The collective CPU model does not simulate independent waves.
