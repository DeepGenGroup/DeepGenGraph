Each invocation creates a UNIQUE runs/<variant>-<label>-XXXXXX directory, so
retests never overwrite earlier results. Each directory saves input.ll,
launch.json, input.sha256, compile.log, kernel.hsaco, kernel.hsaco.amdgcn,
assembly_counts.json, benchmark.log and result.json. result.json includes GPU
correctness, median, SDPA ratio and raw timing samples. No PMC profiler is run
automatically; use the same PMC command/configuration as previous experiments.

run.sh executes these main commands in that isolated directory:
  bash /data2/xsl/DeepGenGraph/GenHsaco.sh input.ll 3 kernel.hsaco
  python3 /data2/xsl/DeepGenGraph/launchKernel.py --hsaco kernel.hsaco \
    --config launch.json --warmup 50 --repeat 200 --json-output result.json

Toolchain paths follow GenHsaco.sh: LLVM_DIR, ROCM_BC and GPU_ARCH. Keep the
previously tested values; defaults are /workspace/deepgengraph/dtk/aillvm/bin,
/opt/dtk/amdgcn/bitcode and gfx936, respectively. If these paths differ in your
DTK environment, export the corresponding existing toolchain paths first.
